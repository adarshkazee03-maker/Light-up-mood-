# Sunshine World 🌻
Open `index.html` to run locally (no build, no backend).
Edit texts only in `config.js`.

## Journeys and worlds
Open `index.html`, choose **Let's explore** → **Okay, let's go!**, then choose any mood. SAD and TIRED offer their own interactive journeys; ANGRY, BORED, and HAPPY include bubble, sunflower-catching, emoji, gift, and celebration interactions.

Choose **Her Little Universe** for Fashion Paradise, Snack Paradise, Cosy Rainy World, Dream Adventure, and Sunflower Garden. Choose **Secret Surprise** to open the gift, find all three sunflower clues, and reveal the personal letter.

All personal copy, compliments, game prompts, and world content are editable in `config.js`. Rain sound is optional, starts muted, and only plays after selecting its control.

## Deploy on GitHub Pages
1. Create a GitHub repository and upload the project files, keeping `index.html`, `style.css`, `script.js`, and `config.js` at the repository root.
2. Push the files to the repository's `main` branch.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose **main** and **/(root)**, then select **Save**.
5. Wait for the Pages deployment to finish under the **Actions** tab. Open the URL shown in **Settings → Pages** (usually `https://<username>.github.io/<repository>/`).

No build step, backend, or package installation is required.

## Assets
`assets/images` (illustrations/photos you have rights to), `assets/audio` (optional rain/music, never autoplay), `assets/icons`.
